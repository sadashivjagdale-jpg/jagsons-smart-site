# JAGSONS SMART SITE™ — Project Master Stable

Apps Script + Google Sheet + Drive + GitHub.

## Project Master
Project Name, unique Project Code, Client, Department, Tender No., Work Order No., Contract Value, Start/Completion Date, Project Manager, Site Engineer, Project Type, GPS, Geofence Radius, Physical/Financial Progress, Status, Location, Edit/Update/Delete and duplicate prevention.

## Preserved modules
DPR, Attendance, Material, Machinery, Vehicles, Plant, Measurement/MB, RA Bill, Purchase, Quality, Safety, Documents, Reports, Jagsons AI.

## Deploy
Replace `Code.gs` and `Index.html` in the existing Apps Script project, run `setupJagsonsSmartSite()` once, then Deploy → Manage deployments → Edit → New version → Deploy.

Expected header: `PROJECT MASTER STABLE · ALL MODULES`.
